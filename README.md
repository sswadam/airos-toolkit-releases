# airOS Toolkit downloads

Public installers and portable packages for **airOS Toolkit**.

- Source code stays in a **private** repository and is not mirrored here.
- Releases here are Windows packages only (setup installer, portable ZIP, and SHA-256 checksum files).
- A checksum next to a download detects damaged files. It does **not** prove who published the file; only code signing does that.
- The app checks this repository for updates. No GitHub token is required for that check.

Until a release is published here, the app correctly reports that no update package is available yet.
